# منبع داده و روش بازسازی

## منبع رسمی

[NCI Genomic Data Commons](https://portal.gdc.cancer.gov/projects/TCGA-BRCA)، پروژهٔ TCGA-BRCA، فقط دسترسی Open.

## نسخه و تاریخ دریافت این اجرا

- نسخهٔ داده: **GDC Data Release 46.0**، منتشرشده در **۱۰ اوت ۲۰۲۶**.
- تاریخ پایان دریافت: **۱۱ آبان ۱۴۰۵ (۲ نوامبر ۲۰۲۶)، ساعت ۱۷:۲۶ به وقت تهران**؛ زمان ثبت‌شدهٔ UTC برابر `2026-11-02T13:56:37.590026+00:00` است.
- منبع ثبت این اطلاعات: `reports/phase1/provenance.json` و `data/raw/gdc_status.json`.
- سال تشخیص موجود در این استخراج از **۱۹۸۸ تا ۲۰۱۳** است. این بازه، سال تشخیص است؛ تاریخ تقویمی دقیق جمع‌آوری همهٔ نمونه‌ها در استخراج مورد استفاده در دسترس نیست.

تاریخ دریافت، تاریخ انتشار داده و تاریخ تشخیص/جمع‌آوری نمونه سه مفهوم جدا هستند. دریافت تازه از سرویس جاری GDC ممکن است با انتشار آیندهٔ داده تغییر کند؛ برای مقایسهٔ دقیق، نسخه و اثر انگشت‌های ثبت‌شده بررسی شوند.

## داده‌های مورد استفاده

- اطلاعات بالینی همهٔ بیماران، از مسیر `/cases` با گسترش `demographic,diagnoses`
- فرادادهٔ فایل‌های Gene Expression Quantification، RNA-seq، روش STAR - Counts، از مسیر `/files`
- بیان چهار ژن MKI67، ESR1، PGR و ERBB2 از `/gene_expression/values`، با واحد `uqfpkm`
- فایل تومور اولیهٔ مشخص برای هر بیمار دارای چند فایل RNA؛ همچنین شش فایل تک‌نمونه‌ای برای کنترل عددی خروجی رابط

| فایل محلی | محتوا |
|---|---|
| `data/raw/clinical.json` | پاسخ بالینی همهٔ بیماران و تشخیص‌ها |
| `data/raw/rna_files.json` | فهرست فایل‌های عمومی RNA و ارتباط بیمار/نمونه/فایل |
| `data/raw/case_expression.tsv` | بیان چهار ژن در سطح بیمار، برای استفاده در موارد تک‌فایلی |
| `data/raw/selected_files.json` | انتخاب قطعی یک فایل تومور اولیه برای هر بیمار واجد شرایط |
| `data/raw/rna/<file UUID>.tsv` | فایل‌های مستقیم نمونهٔ منتخب در موارد چندفایلی و کنترل‌های تک‌فایلی |
| `data/raw/requests/` | بدنهٔ درخواست‌های استفاده‌شده برای دریافت |

فهرست دقیق UUID، نام فایل و MD5 منبع در `reports/phase1/selected_files.csv` و `reports/phase1/sample_file_audit.csv` ثبت شده است. شناسهٔ ژن‌ها و قواعد انتخاب در `config/phase1.json` قرار دارند.

خود رابط بیان ژن در سطح بیمار خروجی می‌دهد و شناسهٔ نمونهٔ انتخابی را همراه خروجی ارائه نمی‌کند. بنابراین برای بیمار دارای چند فایل، از خروجی آن به‌عنوان بیان نمونهٔ منتخب استفاده نمی‌کنیم و مقدار را از فایل تومور اولیهٔ مشخص استخراج می‌کنیم.

## بازسازی

```bash
python3 src/fetch_data.py
python3 src/analyze_phase1.py
```

تاریخ دریافت، نسخهٔ GDC، درخواست‌ها و پاسخ‌های خام در `data/raw/` ذخیره می‌شوند. این پوشه در GitHub قرار نمی‌گیرد. خلاصهٔ دریافت و اثر انگشت فایل‌ها در `reports/phase1/` ثبت خواهد شد.

شناسهٔ اتصال case UUID است؛ تطابق بارکد بیمار با نمونه نیز کنترل می‌شود. جدول اصلی در سطح بیمار است. قواعد انتخاب نمونه، تشخیص اصلی و مقیاس‌ها در `config/phase1.json` و `PROJECT_CARD.md` آمده‌اند.

`data/processed/patients_phase1.csv` همهٔ بیماران پروژه و پرچم وجود داده‌ها را دارد. `data/processed/multimodal_cohort_phase1.csv` فقط بیماران جدول اصلی دارای هر دو وجه را شامل می‌شود. ستون `complete_main_variables` کامل‌بودن همهٔ متغیرهای اصلی را مشخص می‌کند.

## توضیح مقیاس

در این اجرا از FPKM-UQ استفاده می‌شود، نه TPM. تبدیل نمایشی دقیقاً `log2(FPKM-UQ + 1)` است و مقدار نرمال‌شدهٔ اصلی هم حفظ می‌شود. این مقادیر، بیان RNA هستند و با نتیجهٔ آزمایش پروتئینی گیرنده‌ها یکسان فرض نمی‌شوند.
