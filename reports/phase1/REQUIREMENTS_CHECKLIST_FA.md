# تطبیق خروجی‌های فاز اول با دستور پروژه

| الزام | شاهد در خروجی |
|---|---|
| منشأ داده و جمع‌آوری | بخش ۱ گزارش، data/README.md، provenance.json |
| واحد مشاهده و ساختار | بخش ۲ گزارش، sample_file_audit.csv و diagnosis_audit.csv |
| نمونه‌گیری و قابلیت تعمیم | بخش‌های ۱ و ۸ گزارش |
| نوع و مقیاس متغیرها | کارت پروژه و جدول متغیرهای گزارش |
| ممیزی کیفیت | quality_issues.csv، جدول‌های گمشدگی و بخش ۸ گزارش |
| فراوانی و توزیع تجربی | categorical_frequencies.csv، هیستوگرام‌ها |
| مرکز و پراکندگی | descriptive_statistics.csv؛ میانگین، میانه، SD، چارک‌ها و IQR |
| حداقل چهار نمودار | هفت شکل در figures/phase1/ و گزارش |
| مقایسهٔ توصیفی گروه‌ها | mki67_by_stage.csv و نمودار جعبه‌ای |
| نهایی‌کردن سؤال | بخش ۸ گزارش |
| ب۱: دو نوع داده و سطح تحلیل | دادهٔ بالینی و RNA-seq؛ توضیح سطح بیمار/نمونه/فایل |
| ب۲: تطبیق شناسه‌ها و جریان داده | data_flow.csv، selected_files.csv و sample_file_audit.csv |
| ب۳: ممیزی مستقل دو وجه | خلاصه‌های clinical_before_merge و molecular_before_merge |
| ب۴: الگوی نبود وجه و انتخاب نمونه | modality_availability.csv، clinical_selection_comparison.csv |
| ب۵: ویژگی‌های مولکولی محدود و توجیه‌شده | چهار ژن ثبت‌شده در کارت، منبع علمی و توزیع‌های هر چهار ژن |
| گزارش PDF | reports/phase1.pdf |
| کارت پروژه | PROJECT_CARD.md |
| کد قابل بازتولید و راهنما | src/، requirements.txt، README.md و data/README.md |

ثبت نهایی موضوع در سامانه/فهرست درس و تحویل بسته در CW، اقدام‌های حساب دانشجو هستند. برچسب phase-1 باید پس از نهایی‌شدن خروجی‌ها در مخزن قرار بگیرد.

## مواردی که جداگانه باید تأیید شوند

- ثبت موضوع در فهرست مرکزی درس، طبق روش اعلام‌شدهٔ تیم دستیاری
- وجود همهٔ فایل‌های تحویل و برچسب `phase-1` در GitHub
- انتقال تاریخچهٔ واقعی ثبت مراحل کار به مخزن؛ بارگذاری فایل‌ها از مرورگر، ثبت‌های محلی Git را منتقل نمی‌کند
- بارگذاری بسته در CW و دسترسی ارزیاب به مخزن
- مطالعه و توانایی توضیح انتخاب داده، اتصال، گمشدگی، خلاصه‌ها و نمودارها در دفاع

تاریخ دقیق جمع‌آوری همهٔ نمونه‌ها در استخراج موجود در دسترس نیست. در گزارش و راهنمای داده، این محدودیت و تفاوت آن با سال تشخیص صریح ثبت شده است؛ تاریخ دریافت و نسخهٔ انتشار مشخص‌اند.
