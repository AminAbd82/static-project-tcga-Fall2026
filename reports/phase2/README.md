# فاز دوم | احتمال و توزیع‌ها در TCGA-BRCA

ورودی همان جدول بیمارمحور فاز اول از GDC Data Release 46.0 است. در تحلیل اصلی، گروه‌های مرحلهٔ I–II و III–IV را با دو گروه بیان MKI67 تا میانه و بالاتر از میانه مقایسه می‌کنیم. میانه از همهٔ مقادیر معتبر بیان، بدون استفاده از سن یا مرحله، محاسبه می‌شود. احتمال‌ها توصیف گروه‌های موجود در داده‌اند.

| خروجی | مسیر |
| --- | --- |
| گزارش فارسی | [phase2.pdf](../phase2.pdf) |
| شمارش و احتمال مشترک | [event_table.csv](event_table.csv) |
| توزیع شمارش با و بدون جایگذاری | [count_pmf.csv](count_pmf.csv) |
| خلاصهٔ عددی و اثر انگشت داده | [results.json](results.json) |
| نمودارها | [figures/phase2](../../figures/phase2) |
| تنظیمات تحلیل | [config/phase2.json](../../config/phase2.json) |

از ریشهٔ مخزن اجرا کنید:

```bash
python3 -m pip install -r requirements.txt
python3 src/analyze_phase2.py
python3 src/build_phase2_report.py
```

برای ساخت PDF، XeLaTeX و بستهٔ xepersian لازم است. تحلیل مستقیماً از `data/processed/multimodal_cohort_phase1.csv` استفاده می‌کند. اگر فایل ورودی موجود باشد، دریافت مجدد داده‌های خام لازم نیست.

مطابق شرح رسمی فاز دوم، تحلیل شامل احتمال حاشیه‌ای، مشترک و شرطی، مقایسه با الگوی استقلال، محاسبهٔ بیز، مدل شمارش، میانگین و واریانس، بررسی نموداری تقریب نرمال و کوواریانس سن و بیان ژن در سطح بیمار است. تمام مراحل تحلیل و گزارش از روی فایل‌های این مخزن قابل بازتولیدند.
